# Local Knowledge Base

THAI ยินดีต้อนรับสู่ **Local Knowledge Base**!  
ระบบจัดการความรู้ส่วนตัวขนาดเล็กที่ทำงานบนเครื่องคอมพิวเตอร์ของคุณเอง (**Localhost**) ช่วยให้คุณสามารถจดบันทึก, จัดเก็บบทความ, และจัดการลิงก์ที่ใช้งานบ่อยๆ ได้อย่างง่ายดายและเป็นส่วนตัว  
ข้อมูลทั้งหมดจะถูกเก็บไว้ในเครื่องของคุณ ทำให้มีความปลอดภัยและรวดเร็วในการเข้าถึง

## ✨ คุณสมบัติเด่น (Features)

- 📝 **จัดการบทความ**: สร้าง, แก้ไข, ลบ, และอ่านบทความได้อย่างไม่จำกัด

- 🔍 **ค้นหาอัจฉริยะ**: ค้นหาเนื้อหาภายในบทความทั้งหมดได้อย่างรวดเร็ว พร้อมไฮไลท์คำที่ค้นหา
*<img width="1581" height="331" alt="image" src="https://github.com/user-attachments/assets/ab05ab3f-893b-4404-9f92-15fee34134d9" />*
- 📌 **ปักหมุดบทความ**: ปักหมุดบทความสำคัญเพื่อให้แสดงอยู่ด้านบนสุดเสมอ
*<img width="1574" height="304" alt="image" src="https://github.com/user-attachments/assets/ffcdcfc3-d425-4d35-ac10-163eedfa4627" />*
- 🔗 **จัดการลิงก์ด่วน (Quick Links)**: เพิ่มลิงก์ที่เข้าใช้งานบ่อยๆ ได้สะดวก  
- 📂 **ลิงก์ไปยังไฟล์ในเครื่อง**: รองรับการสร้างลิงก์แบบ `fronthub:your/path` เพื่อเปิดไฟล์หรือโฟลเดอร์ในเครื่องโดยตรง  
- 💾 **สำรองและกู้คืนข้อมูล**: สำรองเป็นไฟล์ `.json` และนำเข้ากลับมาได้ง่าย  
- 🌙 **Dark Mode**: ดีไซน์สวยงาม สบายตา

## 💻 เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend**: HTML, JavaScript, Tailwind CSS  
- **Backend**: Node.js, Express.js  
- **Database**: ไฟล์ JSON (`knowledge-base-data.json`)  

---

## 🚀 วิธีการติดตั้งและใช้งาน

### สิ่งที่ต้องมี (Prerequisites)
- ติดตั้ง [Node.js (LTS)](https://nodejs.org/)  
- ตรวจสอบว่า Node.js ติดตั้งแล้ว โดยรันคำสั่ง:

```bash
node -v
````

---

### ขั้นตอนการติดตั้ง (Installation)

1. ดาวน์โหลดไฟล์โปรเจกต์ และเก็บไว้ในโฟลเดอร์เดียวกัน
2. เปิด **Terminal / CMD** แล้วเข้าไปยังโฟลเดอร์โปรเจกต์

   * (Windows) สามารถพิมพ์ `cmd` ใน Address Bar เพื่อเปิด CMD ที่โฟลเดอร์นั้นได้ทันที
3. ติดตั้ง Dependencies:

```bash
npm install express cors
```

---

### การรันโปรแกรม (Running the Application)

#### วิธีที่ 1: (ง่ายที่สุดสำหรับ Windows)

* ดับเบิลคลิกที่ไฟล์ `run-server.bat`
* จะมีหน้าต่าง Command Prompt เปิดขึ้น และเซิร์ฟเวอร์จะเริ่มทำงานทันที

#### วิธีที่ 2: (ทุกระบบปฏิบัติการ)

* เปิด Terminal หรือ CMD ที่โฟลเดอร์โปรเจกต์
* รันคำสั่ง:

```bash
node server.js
```

* เปิดเว็บเบราว์เซอร์ และเข้าไปที่:
  👉 [http://localhost:3000](http://localhost:3000)

> ⚠️ **หมายเหตุ**: อย่าปิดหน้าต่าง Command Prompt ขณะใช้งาน หากต้องการหยุดเซิร์ฟเวอร์ ให้กด `CTRL + C`

## 📁 โครงสร้างไฟล์ (File Structure)

```
/
├── auto/
│   └── knowledge-base-data.json   # ไฟล์เก็บข้อมูล (สร้างอัตโนมัติ)
├── index.html                     # โครงสร้างหน้าเว็บหลัก
├── script.js                      # โค้ด JavaScript ฝั่ง Client
├── style.css                      # CSS สำหรับปรับแต่งเพิ่มเติม
├── server.js                      # เซิร์ฟเวอร์ Node.js
└── run-server.bat                 # สคริปต์รันเซิร์ฟเวอร์ (Windows)
```

## 💡 การใช้งานเบื้องต้น

* **สร้างบทความใหม่** → คลิกปุ่ม "สร้างบทความใหม่" (สีน้ำเงิน มุมขวาบน)
* **แก้ไข / ลบ / ปักหมุด** → ไอคอนจะแสดงที่มุมขวาบนของการ์ดบทความเมื่อชี้เมาส์
* **อ่านบทความเต็ม** → คลิก "หัวข้อ" ของบทความ
* **เพิ่มลิงก์ด่วน (Quick Links)** → คลิกปุ่ม "+ เพิ่มลิงก์"
* **สำรองข้อมูล** → คลิก "สำรองข้อมูล" เพื่อดาวน์โหลดไฟล์ `kb-backup-YYYY-MM-DD.json`
* **กู้ข้อมูล** → คลิก "กู้ข้อมูล" และเลือกไฟล์ `.json` ที่เคยสำรองไว้
